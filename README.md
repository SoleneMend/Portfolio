# Portfolio - Solène Mendes (Francais)

Bienvenue sur le dépôt de mon **portfolio personnel**, développé pour présenter mon profil, mes compétences, mes projets et mon parcours dans le développement web.

 - Voir le portfolio en ligne : [Portfolio](https://solenemend.github.io/Portfolio/)

## Présentation

Ce portfolio a été conçu comme une vitrine de mon travail et de mes compétences en développement web.

Il permet notamment de :

- Découvrir mon profil et mon parcours
- Consulter mes compétences techniques
- Découvrir mes différents projets
- Naviguer sur une interface responsive
- Me contacter

## Technologies utilisées

### Frontend

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)

- **React** - création de l'interface utilisateur
- **Vite** - environnement de développement et build
- **CSS3** - mise en page et responsive design

### Outils

- **Git / GitHub** - gestion du versionnement
- **Biome** - linting et formatage du code
- **npm** - gestionnaire de dépendances

## Structure du projet

```
Portfolio/
├── public/          # Ressources publiques
├── src/             # Code source de l'application
├── dist/            # Build de production
├── package.json
├── vite.config.*
└── README.md
```
La structure peut évoluer au fur et à mesure du développement du portfolio.

## Installation du projet
### 1. Cloner le dépôt

Avec SSH :
```bash
git clone git@github.com:SoleneMend/Portfolio.git
```

Ou avec HTTPS :
```bash
git clone https://github.com/SoleneMend/Portfolio.git
```

### 2. Accéder au projet
```bash
cd Portfolio
```

### 3. Installer les dépendances
```bash
npm install
```

### 4. Lancer le projet
```bash
npm run dev
```
Le projet sera alors accessible à l'adresse indiquée par Vite dans le terminal.

## Scripts disponibles

```bash
npm install         # Installe les dépendances
npm run dev         # Lance le serveur de développement
npm run build       # Génère le build de production dans dist/
npm run preview     # Prévisualise le build de production
npm run check       # Vérifie le code avec Biome
npm run check:fix   # Corrige et formate le code avec Biome
```

## Déploiement

Le portfolio est déployé avec **GitHub Pages** et est accessible en ligne :

**- Portfolio** : [Voir le site](https://solenemend.github.io/Portfolio/)
