React + TypeScript + Vite, lint et format avec Biome.

## Démarrer

```bash
npm install
npm run dev        # serveur de dev
npm run build      # build de production dans dist/
npm run preview    # vérifier les types
npm run check      # vérifier avec Biome
npm run check:fix  # corriger et formater avec Biome
```
